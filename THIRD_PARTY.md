# Bundled WordPress theme

`themes/twentytwentyfive` is the unmodified Twenty Twenty-Five 1.5 distribution from:
https://downloads.wordpress.org/theme/twentytwentyfive.1.5.zip

Theme copyright belongs to the WordPress contributors. The theme is GPL-2.0-or-later. Its included `readme.txt` contains the license and separate asset/font credits. The starter's MIT license does not replace these licenses.

The theme is included because the Playground extension mounts this repository over the complete `wp-content` directory. Without a theme in the repository, that mode hides the default themes from WordPress core.

To update it, review a new official distribution and replace only this bundled directory. Do not modify it for project-specific development; clone a separate theme repository instead.
